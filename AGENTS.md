# Agentes Personalizados - Resuélvelo App

## Agentes de Desarrollo

### 1. Backend Developer (`backend-dev`)
**Especialidad**: API REST, lógica de negocio, base de datos
**Herramientas**: Node.js, Express, Prisma, PostgreSQL
**Responsabilidades**:
- Crear endpoints REST
- Implementar lógica de negocio
- Diseñar esquemas de base de datos
- Optimizar queries SQL
- Implementar autenticación y autorización

### 2. Frontend Developer (`frontend-dev`)
**Especialidad**: Interfaces de usuario, experiencia de usuario
**Herramientas**: React Native, Expo, TypeScript, NativeWind
**Responsabilidades**:
- Crear componentes UI
- Implementar navegación
- Conectar con API backend
- Manejar estado de la aplicación
- Implementar animaciones

### 3. Database Administrator (`database-admin`)
**Especialidad**: Base de datos, modelos, optimización
**Herramientas**: PostgreSQL, Prisma, Supabase
**Responsabilidades**:
- Diseñar esquemas de BD
- Crear migraciones
- Optimizar queries
- Implementar índices
- Gestionar permisos de BD

### 4. Auth Specialist (`auth-specialist`)
**Especialidad**: Autenticación, seguridad, verificación
**Herramientas**: Supabase Auth, JWT, bcrypt
**Responsabilidades**:
- Implementar login/registro
- Gestionar tokens JWT
- Implementar verificación SMS/email
- Manejar recuperación de contraseña
- Implementar 2FA

### 5. Payments Integrator (`payments-int`)
**Especialidad**: Pasarelas de pago, wallet, transacciones
**Herramientas**: PagoMóvil, Mercado Pago
**Responsabilidades**:
- Integrar pasarelas de pago
- Implementar wallet de la plataforma
- Gestionar comisiones
- Implementar reembolsos
- Manejar disputas de pago

### 6. DevOps Deploy (`devops-deploy`)
**Especialidad**: Deploy, CI/CD, infraestructura
**Herramientas**: Docker, Railway, Vercel
**Responsabilidades**:
- Configurar ambientes
- Implementar CI/CD
- Gestionar deployments
- Monitorear rendimiento
- Configurar variables de entorno

### 7. QA Tester (`qa-tester`)
**Especialidad**: Testing, aseguramiento de calidad
**Herramientas**: Jest, Cypress, React Native Testing Library
**Responsabilidades**:
- Escribir tests unitarios
- Implementar tests de integración
- Realizar pruebas E2E
- Reportar bugs
- Verificar regresiones

### 8. UI Designer (`ui-designer`)
**Especialidad**: Diseño de interfaces, UX
**Herramientas**: Figma, Tailwind CSS, NativeWind
**Responsabilidades**:
- Diseñar layouts
- Crear paleta de colores
- Definir tipografía
- Crear componentes UI
- Implementar responsive design

---

## Comandos Útiles

```bash
# Backend
npm run dev          # Iniciar servidor en desarrollo
npm run build        # Compilar TypeScript
npm run db:generate  # Generar cliente Prisma
npm run db:push      # Push schema a BD
npm run db:migrate   # Crear migración

# Mobile
npx expo start       # Iniciar Expo
npx expo start --ios # Iniciar en iOS
npx expo start --android # Iniciar en Android
```
